# Grading Scale

Letter grades map from course averages (0–100). Pass mark is **60**.

| Average | Letter |
| --- | --- |
| ≥ 95 | A+ |
| ≥ 90 | A |
| ≥ 85 | A- |
| ≥ 80 | B+ |
| ≥ 75 | B |
| ≥ 70 | C+ |
| ≥ 65 | C |
| ≥ 60 | D+ |
| ≥ 55 | D |
| ≥ 50 | D- |
| < 50 | Failed (Overall) |

Quality points (calibrated demo rows): `QP = 0.06 × average − 2`.
